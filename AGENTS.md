# Repository guidance

## Canonical skills

- Treat `.agents/skills/leapstyle` and `.agents/skills/leapwp` as the canonical LEAP skill sources.
- `leapstyle` shapes a paper while it is written; `leapwp` packages a finished paper as a working paper and files it on the shelf. Keep the boundary: nothing in `leapstyle` writes a front page, versions a file or copies to `1Research\WorkingPapers\`.
- Make all LEAP skill updates in those directories and keep them tracked in Git.
- Treat copies under user-level Codex directories as installations, not as source files.
- Validate the canonical skill after changing its instructions, references or metadata.
